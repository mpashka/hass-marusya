# llm-wiki-tags — вики

Документация этого репозитория — **вики, читаемая LLM** ([llm-wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)
Андрея Карпатого) **плюс тэги**. Соседние правила: [`docs-layout.md`](docs-layout.md)
(где лежат страницы), [`tags.md`](tags.md) (механизм тэгов).

1. **В каждой значимой директории есть `index.md`** с однострочным описанием
   каждого файла и каждой поддиректории в ней.
2. **Двусторонняя навигация**: родительский индекс ссылается на дочерние
   страницы; каждая страница — обратно на родительский индекс и на связанные.
3. **У детали одна страница-владелец**; остальные ссылаются на неё, а не
   повторяют.
4. Страницы описывают стабильные концепты, а не список изменений. Много
   маленьких страниц об одном лучше одной большой, иерархия лучше плоского списка.
5. **Сначала читай, потом делай.** Перед задачей пройди по `index.md` от корня
   репозитория вниз до файлов, которые будешь трогать.
6. **Обновляй по ходу.** Тем же изменением обнови каждый `index.md`, страницу
   документации и тэг, затронутые тем, что ты добавил, перенёс, удалил или
   изменил по назначению. Документация, разошедшаяся с кодом, — это дефект, а не
   пункт бэклога.
