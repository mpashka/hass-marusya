# Словарь

Родитель: [`index.md`](index.md).

| Термин | Синонимы | Определение |
|---|---|---|
| колонка | Капсула, умная колонка | устройство «Маруся», привязанное к аккаунту Маруси |
| аккаунт Маруси | аккаунт колонки | учётная запись сервера Маруси, рождённая входом в VK; к ней привязаны колонки и провайдеры умного дома |
| сессия Маруси | — | `session_id` + `session_secret` аккаунта Маруси |
| кабинет DIY | кабинет, личный кабинет VK | страницы `vc.go.mail.ru/smarthouse/diy/`: хранят конфигурации DIY одного аккаунта VK |
| сессия кабинета | cookie кабинета | cookie `sh_data`, открывающая кабинет DIY |
| конфигурация DIY | конфигурация, файл DIY, YAML | YAML со списком устройств и их хуков, загруженный в кабинет |
| описание устройств | список устройств | параметр записи аккаунта: сущности HA, имена, комнаты, типы — без адресов и токенов |
| хук | DIY Hook | HTTP-запрос к Home Assistant, который облако Маруси шлёт по голосовой команде |
| токен хуков | — | долгосрочный токен служебного пользователя HA, которым подписаны хуки аккаунта |
| привязка | link | связь аккаунта Маруси с одной конфигурацией DIY провайдера `diy` |
| синхронизация | sync | привести привязанную конфигурацию аккаунта в соответствие с описанием устройств |
| отпечаток | fingerprint | `sha256` текста конфигурации DIY, по которому синхронизация видит изменение |
| запись | config entry | запись интеграции в Home Assistant: аккаунт колонки или сессия кабинета |
