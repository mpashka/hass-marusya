# Что интеграция обещает

Родитель: [`../index.md`](../index.md).

`marusya_diy` подключает колонки «Маруся» к Home Assistant через DIY Hooks без телефона:
человек по разу входит в VK на каждый аккаунт колонки и раз в 13 месяцев даёт сессию кабинета,
остальное — загрузку описания, привязку и обновление при смене устройств — интеграция делает сама.

Не делает: не управляет колонкой (громкость, будильники), не привязывает колонку к аккаунту,
не подключает других провайдеров умного дома, не читает показания датчиков — DIY Hooks умеют
только включить, выключить и прочитать состояние.

- [`devices.md`](devices.md) — описание устройств: формат, умолчания, как его задаёт скрипт.
- [`usecases.puml`](usecases.puml) — кто и зачем пользуется интеграцией.

## Сценарии

Шаги считаются от страницы «Интеграции» Home Assistant.

| Сценарий | Кто, как часто | Шаги человека |
|---|---|---|
| Добавить аккаунт колонки | человек, раз на аккаунт VK | «Добавить» → Маруся DIY → «Аккаунт колонки» → ссылка входа → вход в VK → скопировать адрес → вставить → «Отправить»: **8** |
| Дать сессию кабинета | человек, раз в 13 месяцев | «Добавить» → Маруся DIY → «Сессия кабинета» → вставить значение cookie `sh_data` → «Отправить»: **5** плюс DevTools браузера |
| Задать или сменить устройства | скрипт при каждом прогоне; человек — «Настроить» на записи аккаунта | скрипт: 0; человек: «Настроить» → правка → «Отправить»: **3** |
| Сессия истекла | интеграция сама | уведомление «Требуется повторная настройка» на записи → тот же вход, что при добавлении |
| Посмотреть, всё ли в порядке | человек | запись аккаунта: сущность «Состояние DIY» — привязано / ошибка словами |

## Обещания

- **Изменение устройств доезжает само.** Сменилось описание устройств, адрес Home Assistant или
  токен хуков — интеграция загружает новую конфигурацию, перепривязывает аккаунт и удаляет
  прежнюю. Не сменилось — ничего не делает: повторный прогон скрипта бесплатен.
- **Хуки подписаны своим токеном.** Интеграция заводит в Home Assistant пользователя без прав
  администратора и долгосрочный токен для хуков аккаунта; удаление записи отзывает токен.
  Токен в описание устройств не входит — скрипту секреты Home Assistant не нужны.
- **Отказ называется на записи.** Истёкшая сессия Маруси или кабинета — повторная настройка
  именно той записи; отказ сервера — состояние «ошибка» с причиной и шагом, на котором
  сломалось.
- **Аккаунт не остаётся без DIY по вине интеграции.** Не удалось привязать новую конфигурацию
  после отвязки — интеграция возвращает прежнюю.
